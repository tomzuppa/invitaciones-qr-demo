# Invitaciones QR · Demo

Demo de Baobyte de un sistema de invitaciones con código QR:

1. Carga de invitados desde CSV y organización por grupos.
2. Pases con QR válidos para varios lugares, activados por persona o por grupo.
3. Diseño de la invitación con logo o imagen propia, descargable en PNG o ZIP.
4. Página de confirmación para el invitado y tablero con la tasa de confirmación.

Acceso de prueba: usuario `admin`, contraseña `demo2026`.
Es una demo sin servidor: los datos viven solo en el navegador de quien la abre.
